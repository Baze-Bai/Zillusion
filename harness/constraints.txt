# Why this file exists: every dependency in pyproject.toml is an unbounded ">="
# floor, so a plain "pip install -e ." resolves against PyPI-of-the-day and a
# tree that worked last month can break with no commit in between. That is not
# hypothetical here — mcp 2.0 removed mcp.server.fastmcp and silently left the
# agent with zero browser tools until the <2 cap landed.
#

#     pip install -c constraints.txt -e .
# Constraints cap what gets installed without forcing anything in, so a
# platform that does not need an entry simply ignores it.

#     uv pip compile pyproject.toml --python-platform linux --python-version 3.12 -o constraints.txt
